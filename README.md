# 🐍 Python 学习系统

一款运行在终端的 Python 交互式学习工具，涵盖理论、练习、陷阱题、挑战题和卡码网算法实战。

## ✨ 功能特色

| 模块 | 内容 |
|------|------|
| 📖 **理论** | 37 个阶段，覆盖 Python 基础到高级主题 |
| ✏️ **练习** | 198 道精选练习题，即时反馈 |
| ⚠️ **陷阱题** | 常见错误与易错点剖析 |
| 🏆 **挑战题** | 综合应用，提升编程能力 |
| 💻 **卡码网** | 入门 / 进阶 / 挑战三个难度级别的算法练习 |
| 🎮 **游戏化** | XP 经验值、成就徽章、学习统计 |

## 🚀 快速开始

### 环境要求
- Python 3.8+

### 运行
```powershell
python start_learn.py
```

### 菜单说明
- `[v]` 已完成阶段
- `[r]` 有复习题待做
- `[R]` 复习题已完成

## 📁 项目结构

```
python_learn/
├── __init__.py            # 包初始化
├── learn.py               # 主程序入口
├── ui.py                  # 界面与颜色输出
├── sandbox.py             # 代码沙盒（安全执行用户代码）
├── game.py                # XP 与成就系统
├── stats.py               # 学习统计
├── theory_*.py            # 各阶段理论内容（8个文件）
├── exercises_*.py         # 各阶段练习题（8个文件）
├── pitfalls.py            # 陷阱题题库
├── challenges.py          # 挑战题题库
├── kamacoder_practice.py  # 卡码网算法题库
├── projects.py            # 综合实战项目
└── review.py              # 复习关卡
```

## 🗺️ 学习路径（6篇37阶段）

```
第一篇 Python基础 (S1-S13)
第二篇 Python进阶 (S14-S18)
第三篇 工程基础 (S19-S21)
第四篇 数据方向 (S22-S29)
第五篇 自动化与桌面 (S30-S33)

```
