# 🐍 Python 学习系统

一款运行在终端的 Python 交互式学习工具，涵盖理论、练习、陷阱题、挑战题和卡码网算法实战。

---

## ✨ 核心特性

### 📖 六大篇章 · 37 个阶段

从 Python 基础到高级应用，循序渐进的学习路径：

| 篇章 | 阶段 | 核心内容 |
|------|------|----------|
| **第一篇 Python 基础** | S1-S13 | 变量、条件、循环、函数、模块、文件操作、异常处理 |
| **第二篇 Python 进阶** | S14-S18 | 正则表达式、面向对象、模块包管理、生成器与装饰器、爬虫基础 |
| **第三篇 工程基础** | S19-S21 | API 开发、测试与调试、设计模式 |
| **第四篇 数据方向** | S22-S29 | 数据处理、数据可视化、数据库操作、异步爬虫、爬虫工程化 |
| **第五篇 自动化与桌面** | S30-S33 | 办公自动化、系统监控、GUI 开发、项目实战 |
| **第六篇 架构与算法** | S34-S37 | 设计模式进阶、算法基础、安全编程、架构设计 |

### ✏️ 多维度练习体系

| 练习类型 | 数量 | 特色 |
|----------|------|------|
| **练习题** | 198 道 | 每阶段配套练习，即时运行验证 |
| **陷阱题** | 75 条 | 常见错误与易错点剖析，避开新手坑 |
| **挑战题** | 74 道 | 综合应用，提升编程能力 |
| **复习题** | 12 组 | 巩固已学知识，防止遗忘 |
| **卡码网** | 30 题 | 入门 / 进阶 / 挑战三个难度，实战算法 |
| **实战项目** | 37 个 | 真实场景应用，学以致用 |

### 🎮 游戏化学习体验

- **XP 经验值系统**：完成练习、挑战获得经验值，量化学习进度
- **成就徽章**：解锁里程碑成就，激励持续学习
- **学习统计**：追踪学习时长、完成率、正确率
- **复习提醒**：`[r]` 标记待复习阶段，`[R]` 标记已完成

## 🚀 快速开始

### 环境要求
- Python 3.8+
- 无需安装额外依赖（使用标准库）

### 运行方式

**直接运行**
```powershell
python start_learn.py
```

### 菜单说明
| 标记 | 含义 |
|------|------|
| `[v]` | 已完成阶段 |
| `[r]` | 有复习题待做 |
| `[R]` | 复习题已完成 |

## 🎯 项目优势

### 1. 🖥️ 纯终端运行，零配置启动
- 无需浏览器、无需 IDE 插件、无需在线账号
- 一行命令即可开始学习
- 适合服务器环境、远程开发、离线学习

### 2. 🔒 安全沙盒执行
- 用户代码在隔离环境中运行
- 防止恶意代码影响系统
- 支持超时控制和异常捕获

### 3. 📚 理论 + 实践一体化
- 每个阶段先学理论，再做练习
- 练习题即时运行验证，看到真实输出
- 陷阱题帮助识别常见错误模式

### 4. 🇨🇳 中文原生支持
- 全中文界面和题目
- 适合国内学习者，无语言障碍
- 卡码网算法题库（国内知名平台）

### 5. 🔄 完整复习机制
- 智能复习触发：学完特定阶段后自动提醒复习
- 复习关卡涵盖多个相关阶段的知识点
- 防止"学完就忘"

### 6. 📊 进度持久化
- 学习进度自动保存到本地
- 下次启动自动恢复
- XP、成就、完成记录永不丢失

## 📁 项目结构

```
.
├── start_learn.py       # 🚀 启动入口（从此运行）
└── python_learn/        # 项目核心目录
    ├── __init__.py      # 包初始化
    ├── learn.py         # 主程序入口
    ├── ui.py            # 界面与颜色输出
    ├── sandbox.py       # 代码沙盒（安全执行用户代码）
    ├── game.py          # XP 与成就系统
    ├── stats.py         # 学习统计
    ├── theory_*.py      # 各阶段理论内容（8个文件）
    ├── exercises_*.py   # 各阶段练习题（8个文件）
    ├── pitfalls.py      # 陷阱题题库
    ├── challenges.py    # 挑战题题库
    ├── kamacoder_practice.py  # 卡码网算法题库
    ├── projects.py      # 综合实战项目
    └── review.py        # 复习关卡
```
